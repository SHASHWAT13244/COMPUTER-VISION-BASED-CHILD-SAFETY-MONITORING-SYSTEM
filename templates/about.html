About This Project

Computer Vision-Based Child Safety Monitoring System

This project develops an intelligent real-time monitoring system using Computer Vision & Deep Learning to analyze camera feeds for child safety in homes, schools, and daycares.

Key Features:
  • Real-time child detection & tracking using YOLOv8
  • Activity recognition (walking, running, sitting) using LSTM
  • Pose estimation for safety using MediaPipe
  • Unsafe behavior detection (falls, climbing, running in danger zones)
  • Alert generation with visual and audio notifications
  • Web-based interface for remote monitoring
