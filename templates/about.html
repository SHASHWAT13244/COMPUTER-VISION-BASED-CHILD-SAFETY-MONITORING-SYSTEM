Child Safety Monitoring System

A real-time, AI-powered surveillance system that detects children in a video feed, estimates their body posture, classifies their activity with a deep-learning LSTM model, and raises alerts whenever a potentially unsafe situation is recognized.

YOLOv8 detection MediaPipe pose PyTorch LSTM Flask + Socket.IO OpenCV Multi-channel alerts
What the system does
Person Detection

YOLOv8 locates children in each frame, drawing bounding boxes and confidence scores.

Pose Estimation

MediaPipe extracts 33 body landmarks (shoulders, elbows, hips, knees, ankles …).

Activity Recognition

A 30-frame sequence of keypoints is classified by an LSTM into one of five activities.

Safety Rule Engine

Rule-based logic flags unsafe behaviour — falls, climbing, running in restricted areas.

Alert Generation

Caregivers are notified instantly via desktop, email, Telegram, SMS or webhook.

Live Dashboard

Web UI shows the video stream, current activity, confidence, FPS and full alert history.

Processing pipeline
1. Video Input — frame captured from webcam / CCTV via OpenCV
2. Object Detection — YOLOv8 (every Nth frame for real-time throughput)
3. Pose Estimation — MediaPipe Pose → 33 landmarks × (x, y, z)
4. Sequence Buffer — rolling window of 30 frames (99 features per frame)
5. LSTM Classifier — walking · running · sitting · falling · climbing
6. Safety Rules — confidence threshold + activity + pose heuristics
7. Alert / Dashboard — Socket.IO push + MJPEG stream to browser
